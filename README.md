# معركة الشلة — Shilla Fight

لعبة قتال ثنائية في المتصفح: لاعبين على نفس الجهاز، ضد الكمبيوتر، أو **أونلاين** بكود غرفة.

- `index.html` — اللعبة (كمبيوتر وجوال، أزرار اللمس تطلع لحالها في الجوال)
- `mobile.html` — نسخة الجوال (أزرار اللمس دايماً) → الرابط `/mobile`
- `src/` — ملفات المصدر. بعد أي تعديل شغّل `python3 src/build.py` عشان يتحدث `index.html` و `mobile.html`

## النشر على Vercel
Vercel → **Add New → Project** → اختر هذا المستودع → **Deploy**. ما يحتاج أي إعدادات (موقع ثابت).
أي تعديل ينرفع للمستودع ينزل في الموقع تلقائياً.

## الأونلاين
«أونلاين» ← «إنشاء غرفة» ← أرسل الكود لصاحبك ← هو يختار «دخول بكود».
الاتصال مباشر بين الجهازين (WebRTC) عن طريق PeerJS.
