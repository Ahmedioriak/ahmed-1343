# معركة الشلة — Shilla Fight

لعبة قتال ثنائية في المتصفح: لاعبين على نفس الجهاز، ضد الكمبيوتر، أو **أونلاين** بكود غرفة.

## التشغيل على ويندوز

- افتح `index.html` للعب مباشرة، أو `mobile.html` لتجربة أزرار اللمس.
- للتشغيل عبر خادم محلي، افتح `start-local.cmd` مع Node.js مثبتًا. يفتح اللعبة على `http://127.0.0.1:8043/`. اترك نافذة التشغيل مفتوحة أثناء اللعب.
- «بابا الوه» في الصف الثاني في النسخة الأساسية. في التدريب، جرّب **قدّام + R** للهوز و**E** للماء و**S + E** للبطاطس. تظهر بقية الحركات والقاضية في قائمة الحركات أثناء الإيقاف المؤقت.
- «المزارع» في آخر خانة من الصف الثاني. جرّب **قدّام + R** للمعول و**E** لعربة الحصاد و**S + E** لوابل الخضروات.
- لبدء «أسطورة الدرع الأخير»، ادخل **العالم المفتوح + القصة**، اختر خانة حفظ ثم **القصة ٣** أو اضغط **3**. تبدأ بالوحش بلبس الطباخ في مطعم الشلة. تمرّ بالفريج والديوانية، ثم يبدّل الوحش إلى بدلة المتدرّب في الحلبة قبل التوجّه إلى قلعة ناصر. لكل قصة حفظ مستقل لمراحلها.

### تسجيل أصوات القصة الثالثة

شغّل `start-local.cmd` واترك النافذة مفتوحة، ثم افتح [صفحة تسجيل القصة](http://127.0.0.1:8043/record-fortress). اختر خدمة التسجيل وأدخل مفتاحك في الصفحة. تقدر تجرّب جملة واحدة بزر «اسمع» قبل تسجيل الكل.

بعد تنزيل ZIP، استورده من مجلد اللعبة في PowerShell عبر `$env:MERGE='1'; python tools/voice/pro_import.py "fortress-voices.zip"; python src/build.py`. تحتاج إلى FFmpeg للاستيراد. يمكن إعادة توليد قائمة التسجيل من السيناريو بالأمر `node tools/voice/make_fortress_lines.cjs`.

## سيرفر الأونلاين (Firebase)
1. https://console.firebase.google.com ← **Create a project**.
2. **Build ← Realtime Database ← Create Database** ← المكان: **Belgium (europe-west1)** ← **Start in test mode**.
3. تبويب **Rules**: الصق محتوى `database.rules.json` واضغط **Publish**.
4. ⚙️ **Project settings ← Your apps ← Web (`</>`)** ← سجّل التطبيق ← انسخ `firebaseConfig`.
5. الصقه في `firebase-config.js` مكان `null` (تقدر تعدّله من GitHub مباشرة).

بعدها اللعبة تربط اللاعبين عن طريق السيرفر. بدون الإعدادات تستخدم اتصال مباشر بين الجهازين.

النسخة الأساسية تستخدم غرفًا منفصلة عن الإصدار الثاني منذ التحديث 1.67. عند تفعيل Firebase، انشر قواعد قاعدة البيانات المرفقة وافتح نفس إصدار اللعبة عند الطرفين.

## الاستضافة
- **Vercel**: Add New ← Project ← اختر هذا المستودع ← Deploy.
- **Firebase Hosting** (اختياري): `npm i -g firebase-tools` ← `firebase login` ← `firebase use --add` ← `firebase deploy`.

## تثبيت اللعبة كتطبيق 📲
افتح رابط موقعك (Vercel) — الأفضل رابط الجوال `/mobile` في الجوال:
- **أندرويد / Chrome / Edge:** الإعدادات داخل اللعبة ← «ثبّت اللعبة كتطبيق»، أو من قائمة المتصفح ⋮ ← «تثبيت التطبيق».
- **آيفون / آيباد:** افتحه في Safari ← زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية».

بعد أول فتح تنحفظ اللعبة في الجهاز وتشتغل **بدون إنترنت** (لاعبين، ضد الكمبيوتر، القصة). الأونلاين يحتاج إنترنت.
كل ما تفتح اللعبة من الشاشة الرئيسية، تتأكد من آخر تحديث بالموقع (أقصى شي ثانيتين ونص) وبعدها تفتح. لو النت بطيء تفتح النسخة المحفوظة، ولما يوصل التحديث تعيد تحميل نفسها وهي في القائمة. رقم الإصدار مكتوب تحت شعار اللعبة.

## لوحة المدير 👑 (`/admin`)
رابط خاص فيك: `رابط-موقعك/admin`. تعرض كل اللاعبين وأسماءهم، ومتى آخر مرة دخلوا، وكم مرة دخلوا، وكم مباراة لعبوا، وآخر شخصية لعبوا فيها، والجهاز اللي يلعبون منه، ومنو يلعب الحين.
تشتغل على نفس سيرفر Firebase حق الأونلاين:
1. سوّ خطوات «سيرفر الأونلاين» فوق (المشروع، والـ Realtime Database، و `firebase-config.js`).
2. في Firebase: **Build ← Authentication ← Get started ← Sign-in method ← Email/Password ← Enable ← Save**.
3. الصق محتوى `database.rules.json` الجديد في تبويب **Rules** واضغط **Publish**.
4. افتح `رابط-موقعك/admin`، واكتب إيميلك وكلمة سر، واضغط **«أول مرة؟ سجّل نفسك كمدير»**.
   - أول حساب يتسجل يصير هو المدير، وبعده محد يقدر يدخل اللوحة غيرك.
   - المرات الجاية تضغط **دخول** بس.

اللعبة تسأل كل لاعب عن اسمه مرة وحدة، ويقدر يغيّره من الإعدادات ← «اسمك في اللعبة».
